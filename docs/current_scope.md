# 当前项目目标与交付要求

更新：2026-10-24。本页是当前目标的唯一入口；旧方法、原RQ和历史任务不自动扩大本页范围。进度见[项目总览](project_status.md)，待办见[当前任务](current_task.md)，事实源为[project_state.json](../project_state.json)。

## 1. 项目在做什么

研究Agent在本地执行单个任务时的资源使用与行为：CPU、内存、磁盘I/O与占用、网络通信、执行时长、工具及具体软件使用。保留连续采样，形成过程图表、逐run数据及同任务重复汇总，不做Agent能力排行榜。

公开trace用来总结操作构成、软件工具集合和样本覆盖；本地运行提供资源观测。两者不能拼成统一总体，不把公开动作源码当实际执行次数或本地资源消耗。

## 2. 当前要交付什么

| 记录项 | 内容与边界 |
| --- | --- |
| CPU | 累计core-s、相邻有效样本差分/实际时间差得到的平均core；百分比注明100%=1core或其他归一化 |
| 内存 | 容器current、进程RSS时间序列和采样峰值，内核peak可得时另列；不同口径不相加 |
| 磁盘I/O | 读写累计字节和B/s；cgroup块服务字节、proc read/write_bytes、rchar/wchar分开，不冒充完整文件系统流量 |
| 磁盘占用 | 任务工作目录、输出、缓存的起止占用及增长；注明表观/实际分配字节、共享和重叠路径，不用镜像大小或整机空闲容量替代 |
| 网络 | 收发累计字节和B/s，注明接口/netns/宿主或transport层；宿主模型API不由禁网任务容器覆盖，整机背景不能冒充任务专属 |
| 时间与行为 | 单任务wall，启动、setup、Agent、评估、清理等已观测阶段；模型请求、工具/软件名、调用次数及结果，bootstrap另计 |
| 模型与结果 | 请求客户端耗时、输入/输出/cache token、可观测重试；评分、正常结束/预算耗尽、工具错误、超时、可观测OOM、infra分列 |
| 环境与进程 | 硬件/OS/kernel/软件/模型身份、CPU/内存限制；可得线程/进程数、user/system CPU、切换与缺页；线程数不是核心数 |
| 采样质量 | 目标与实际间隔、点数、缺读、gap/reset、覆盖窗及可得采集开销；缺失为unknown/unavailable而不是0 |

当前主要采样链目标间隔0.5s，保存真实monotonic时间。一轮任务采很多点与重复运行任务是不同概念，不为凑点数延长任务或补跑。磁盘目录占用优先在run边界统计，不默认每0.5s递归扫描目录、扫描整盘或清缓存。

## 3. 图表与统计

- 单run总览：CPU、内存、磁盘读写、网络收发四个时间对齐面板，分别标单位、scope和已保存阶段/工具事件；另附磁盘占用、时长与工具汇总。
- 累计量与速率分开；无效区间断线、不插值、不补零。共享容器/worker不是单工具独占资源，也不是整机监测。
- 同任务重复保留原始点和独立曲线，报告任务内median/IQR及分位数算法；不把重复当独立task，不拼接成一次run或无依据地平均不同任务曲线。
- reward=1不是资源数据有效的唯一条件；成功、失败、未评估、测量完整性和infra分别说明。
- 模型usage不等于账单或网络字节，客户端请求延迟不等于纯网络/服务端推理时间；真实HTTP尝试、TTFT、远端CPU/GPU等无证据不推算。

## 4. 明确不做什么

- GPU暂不统计，不列缺口。
- 函数/二进制热点、火焰图、perf/PMU、微架构分类、CPU架构诉求、优化和逐工具独占归因不是必交。
- 传统LLM性能对照、多Agent并发、Replay/Scale仅为可选扩展；CPU-02、Replay仍暂停。
- 本页不授权API、Docker/VM、联网、安装、提权、恢复镜像或实验；新代码及批次仍需相应身份与批准。

### AgentX公开语料与客户端专项结果

Full全量分析覆盖393个会话、98,827个请求。另选5个会话各执行3次，形成117个唯一源请求的351次正式客户端执行。该专项只测客户端，没有执行原始业务工具，也没有完整复现原始长输出负载；这些是已记录的证据边界，不是待补跑任务。详见[五类重复实测报告](../reports/analysis/AGENTX-DEEPSEEK-FIVE-REPEATS-v1/summary.md)和[原始证据备份说明](agentx_evidence_backup_20261023.md)。

## 5. 当前事实与下一缺口

已有Coding、Office、Assistant三个主设计，9个固定任务各3点，共27个task×round观察；不是类别总体或统一跨类受控实验。公开操作与软件汇总v3已完成限定验收，部分公开语义与软件运行身份仍未知。

Video已在video-use上完成真实转写、剪辑、局部视觉自检及容器资源采样；PILOT-03/04评分完整但剪切范围未通过（reward=0），原件保留。OpenStoryline已完成一次真实剪辑与官方评分（reward=0，不等于未运行）；ViMax已完成PILOT-04真实媒体生成闭环（19图、8主体+7过渡、40秒成片及33项技术验收）；VideoWeaver已完成原生成、独立离线恢复与真实Agent仅拼接的分阶段真实验证，但修复后完整生成到拼接的单次连续run仍未实测。GUI/VM子域仍未覆盖。不同配置的pilot不作为同质重复。

CPU/内存、有限磁盘I/O与速率、共享netns流量和明确任务目录边界已有新口径实测。仍缺任务/API专属网络字节、共享cache归属及统一最终HTML展示；旧run未采字段不回填。视频可选的多素材/字幕/动画覆盖暂缓，保持原生流程，不默认接入音频模型。新增实验仍需独立批准。
