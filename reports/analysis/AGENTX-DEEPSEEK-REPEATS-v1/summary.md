- 单链基线：耗时 49.66–54.17 s；首内容 P50 1.059–1.219 s；实际输出覆盖 89.86–99.86%。
- 多子代理：耗时 51.22–193.63 s；首内容 P50 0.869–0.900 s；实际输出覆盖 6.44–30.66%。

多子代理中同一长输出请求的自然结束差异值得单列：
- 固定请求索引 9，R1：实际 1,246 / 上限 59,903 token，结束 `stop`，请求耗时 5.64 s。
- 固定请求索引 9，R2：实际 59,903 / 上限 59,903 token，结束 `length`，请求耗时 161.59 s。
- 固定请求索引 9，R3：实际 3,934 / 上限 59,903 token，结束 `stop`，请求耗时 17.31 s。

同一 max_tokens 并不保证相同实际输出量。耗时与实际生成量必须一并阅读；上述观察不能从时长差异中分离网络、缓存、生成内容和服务端负载的影响。

资源只采样本任务拥有的 HTTP 工作进程及其子进程，排除采样父进程与其他会话。RSS 包含请求序列化、响应和证据保存开销；CPU 均值由正式请求窗口内首末样本累计 CPU 差除以实际采样窗口得到，百分比按单核计。采样间隔为每轮工作后 sleep 0.2 秒，实际中位间隔已逐次保存；采样峰值不是连续观测峰值。未测服务器资源或全机网络。HTTP 正文流量不含 TLS、头部和代理开销。

R1 多子代理曾在同一个进程中接续单子代理案例，可能保留堆和连接；本轮 R2/R3 各自启动新进程，仅先做一次探针。R1 单链同样仅先做探针。远程缓存、服务负载、网络和模型别名底层版本均未受控，实际输出也可随自然结束变化。因此这些结果描述所测条件下的波动，不能证明子代理造成加速、缓存造成变化，或推广到整个 AgentX。n=3 不计算置信区间或显著性。P50/P95 均在每轮内部计算，不把所有重复请求当独立样本合并推断。

原始多子代理输出负载仍未复现：重复请求不改变提前 stop 的问题。比例反映输出 token 负载，不是业务成功率。本实验没有执行原始文件、Shell、浏览器等业务工具，也没有复现原始时间间隔。此前输出控制核查见 [五类报告](../AGENTX-DEEPSEEK-FIVE-CASES-v1/summary.md)。
