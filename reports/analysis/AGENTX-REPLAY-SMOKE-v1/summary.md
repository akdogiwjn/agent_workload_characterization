# AgentX 第二步：本地小样回放验证

2026-10-23（北京时间）。第一步的 Full / 256k 全量离线深入分析已完成。本报告单独记录第二步的新实验：**5 个完整会话、117 条请求已完成本地模拟回放，来源 → 回放器导出 → 实际 HTTP 请求的一对一映射通过**。输入及前缀存在已量化的 token 偏差，因此不能称为逐 token 精确复刻。尚未进行第三步真实模型测量。

## 主要结果

| 核验项 | 结果 | 解释 |
| --- | --- | --- |
| 完整会话 / 原生请求 / 显式子代理组 | 5 / 117 / 7 | 每个选中会话全部保留，无请求截断、上下文裁剪或小样内再抽样 |
| 来源、导出、实际 HTTP 请求 | 117 / 117 / 117，一一对应 | 原生索引、请求指纹和 X-Request-ID 联合核对；无重复、遗漏 |
| 输出内容 | 117/117 符合原始输出 token 数 | 直接重组客户端收到的 SSE 文本并重新分词；合计 271,834 token；不只相信服务端 usage |
| 输入长度 | 2/117 完全相等；偏差 −346～+159 token | 绝对偏差中位数 42，P95 161.2 token；总绝对偏差 / 原始总输入为 0.04089%；单请求最大相对偏差 3.125% |
| 共享前缀 | 1,186 对同会话同模型请求，944 对有非零原始共享前缀 | 对这 944 对，实际模板 token 前缀最差长度保留比例 99.954%；455 对缩短、最多少 205 token；8 对长度完全相等，其余 481 对更长 |

## 执行方式与发现

采用官方 `agentx-harness==1.0.7`，未修改安装包源码；以其 `aiperf profile` 兼容入口读取 `weka_trace`。只使用 Qwen/Qwen3-0.6B 的公开分词器，固定 revision `c1899de289a04d12100db370d81485cdf75e47ca`，没有下载或加载模型权重。模拟服务仅绑定 `127.0.0.1`，子进程不传 API 密钥或代理变量，117 条请求均没有 Authorization 头。

为快速核对映射，使用 `--no-fixed-schedule --ignore-trace-delays`、五个根会话并发、固定 seed 42，跳过官方长时性能场景。原始样本文件未改写时间字段。全部模型名称明确改为 `agentx-mock`，统一使用 chat SSE，因此没有验证原生多模型路由和原生 `s/n` 传输差异，也不是官方有效性能提交。

输入偏差的直接观察包括：裸文本重新分词的长度变化、聊天角色/生成前缀增加 token，以及多轮请求重建后的包装变化。`--apply-chat-template` 使导出输入长度与模拟服务独立收到的模板长度一致，但不会保证其与原数据 `in` 完全相同；本次不把每一个偏差强行归因于单一因素。比较依据是实际捕获的 token ID 数组，而非仅回放器预估值。

前两个尝试保留：第一次因沙箱禁止监听 socket 而在服务启动前失败；第二次因官方 1.0.7 的离线加载路径将绝对路径当作 Hub ID 而在请求发送前失败。第三次改用固定 Hub ID + revision，并将已下载文件放入工作树内的标准 HF 缓存目录，成功完成。两个失败尝试均未发送推理 POST，也未删除其日志，见 [attempts.json](attempts.json)。关闭了 GPU 遥测，仅清理本任务拥有的进程。

## 本次完成与后续边界

第二步的请求映射、输出长度、父子关联和实际前缀验证已完成；**不是原业务工具复现、逐 token 原文复刻或原时间调度复现**。没有真实模型、模型服务资源或真实 KV cache 命中测量。模拟服务耗时包含分词、文件压缩和固定等待，不能解释成模型推理性能。

第三步应以本报告中已记录的输入偏差为基线，按目标服务的分词器、模板及上下文上限另建实验身份，再分别采集客户端与真实模型服务端资源。不能把本次 951k 输入能被模拟服务接收，解释为某真实模型支持相同上下文。真实模型实验结果应新建报告，保留第一步原数据统计和本次模拟结果。
